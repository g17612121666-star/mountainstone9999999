# 山石志 · Shanshizhi

随身地质向导。[mountainstone.grok.me](https://mountainstone.grok.me)

中国世界地质公园、国家地质公园、金钉子（GSSP）和城市地质点的野外读层手册：成因、打卡点、路线、观察与购票。只看不挖。

A pocket field guide to geosites in China — UNESCO Global Geoparks, national geoparks, GSSPs, and urban sites. Read the rock. Do not take it.

## 这本手册做什么

- 一张可缩放的中国地质点地图
- 每个点写清岩石、时代、今天能看见什么、先纠一个常见误认
- 打卡点只精确定位到园区或观景台，不提供可盗挖坐标
- 化石：只看不挖
- 中英切换；英文街道底图用 Carto / Esri，不用带水印的商用图商

## 硬边界（写进正文，不靠口头）

- 佘山是城市地质点，**不是**上海的国家地质公园（那一座是崇明岛）
- 张掖彩丘**不是**丹霞山那种丹霞
- 张家界石英砂岩峰林**不是**喀斯特
- 西樵是粗面岩穹丘上的古采石洞，**不是**绳状熔岩 / 夏威夷玄武岩叙事
- 规范域只有 [mountainstone.grok.me](https://mountainstone.grok.me)
